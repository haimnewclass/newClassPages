## 🤖 סוכן ביקורת StoryBrand לדפי נחיתה של HSP

בריפו הזה פועל סוכן אוטומטי שסורק את **כל קבצי ה-HTML שקשורים ל-HSP** (כל קובץ שהנתיב שלו מכיל `hsp`), מנתח כל דף נחיתה לפי עקרונות **StoryBrand (SB7)** ומפיק דוח מפורט בעברית.

### מה הסוכן בודק — 10 מדדים (ציון 0–10 לכל מדד)

1. **דמות (הלקוח כגיבור)** — האם הדף מדבר אל הלקוח ועל הרצונות שלו, ולא על העסק.
2. **בעיה (חיצונית + פנימית)** — האם הכאב של הלקוח מוגדר, כולל הרובד הרגשי.
3. **מדריך (אמפתיה + סמכות)** — האם המותג מציג הבנה של הלקוח לצד הוכחות מקצועיות.
4. **תוכנית (3 שלבים)** — האם יש מסלול פעולה פשוט וברור.
5. **קריאה לפעולה (CTA)** — כפתורים, טפסים והצעות מעבר רכות (חינם / ללא התחייבות).
6. **מה על הכף** — האם ברור מה הלקוח מפסיד אם לא יפעל.
7. **חזון הצלחה** — האם הדף מצייר את החיים אחרי השינוי.
8. **בהירות המסר (Grunt Test)** — כותרת ראשית חדה, בלי ז'רגון.
9. **אורך וסריקוּת** — האם הדף ארוך מדי / קצר מדי, וכמה קל לסרוק אותו.
10. **אמון והוכחה חברתית** — המלצות, נתונים, אחריות.

מהמדדים נגזר **ציון פופולריות כולל 0–100**, והדוח כולל גם:

- ✅ פסיקה על אורך הדף (קצר מדי / תקין / ארוך מדי) עם זמן קריאה משוער.
- 💚 **אילו סוגי קהל יאהבו את הדף** (מחליטים מהירים, אנליטיים, סקפטיים, רגשיים, סורקים במובייל, רגישים למחיר) — ולמה.
- 💔 **אילו סוגי קהל עלולים להירתע** — ולמה.
- 🔧 3 השיפורים החשובים ביותר לכל דף.
- 🔄 **מעקב שינויים** — בכל ריצה הדוח מציין אילו דפי HSP נוספו, השתנו או נמחקו מאז הריצה הקודמת, כולל שינוי בציון.

### מתי הסוכן רץ

ה-GitHub Action‏ ([`.github/workflows/hsp-storybrand-audit.yml`](.github/workflows/hsp-storybrand-audit.yml)) מופעל אוטומטית:

- בכל `push` שמשנה או מוסיף קובץ HTML שקשור ל-HSP;
- בכל Pull Request שנוגע בקבצים כאלה;
- וגם ידנית מלשונית **Actions ‏← HSP StoryBrand Audit ← Run workflow**.

בדחיפה לענף, הדוח המעודכן נכתב אל [`reports/hsp-storybrand-report.md`](reports/hsp-storybrand-report.md) ומוקמט אוטומטית חזרה לריפו, וכן מוצג בעמוד הסיכום של הריצה ב-Actions.

### הרצה מקומית

```bash
python3 tools/hsp_storybrand_audit.py
```

אין תלויות חיצוניות — נדרש רק Python 3.10+. אפשרויות שימושיות:

```bash
python3 tools/hsp_storybrand_audit.py --pattern hsp --report reports/hsp-storybrand-report.md
```

### קובץ דוגמה

הקובץ [`examples/hsp-demo-landing.html`](examples/hsp-demo-landing.html) הוא דף נחיתה לדוגמה שנוצר כדי להדגים את הדוח. אפשר (ורצוי) למחוק אותו ברגע שמעלים דפי HSP אמיתיים — הסוכן יזהה את המחיקה ויעדכן את הדוח.
